# Assistant marketplace scenarios — 18 October 2026

GET /stores/{store}/assistant-options returns the server-owned reference catalog; POST /stores/{store}/assistant-scenarios accepts {message, sku, month, scenario}. Existing JWT/membership and guest origin/tenant/expiry/write quotas apply. This route does not invoke Bedrock, create enrollments, change costs/orders or persist a calculation as a posted ledger. Existing /assistant remains the Bedrock-backed recorded-data assistant.

The scenario schema is strict and rejects foreign campaigns, duplicate campaigns, simultaneous TikTok BCD/FS for one SKU, forged store fields, invalid rates and unconfirmed assumptions. Source is the latest single-SKU order containing the SKU in the selected month, using the existing cost versions. No source order means SKU_HAS_NO_ORDER; multi-SKU basket and fractional quantity are unsupported. Positive whole-unit standard-sale scenarios only; no invented catalog price or cost. The response identifies source order/date/platform and target platform, labels hypothetical/estimated provenance and preserves MOCK/REAL source data. Normal merchant data do not become MOCK, and mock input never becomes a REAL claim.

marketplaceInput clones and replaces source fees/rules/enrollments for the hypothetical target only, clears posted fees/payout/adjustments, and sets simulation. All money, VAT, caps, allocations, margin/TTR, discount and break-even come from the unchanged canonical domain engine margin-v1.1.0. No browser engine or model math is added. Recorded-mode actual posted fee precedence is unchanged. commission/payment entries are merchant-confirmed assumptions, not automatically verified platform rates. Null rate, unknown VAT, required subcategory rate or date before a supported schedule yields INCOMPLETE/null profit. Rule status VERIFIED_FOR_ESTIMATE is an engine gate for explicitly confirmed assumptions, not a claim of merchant rate verification by Shopee/Lazada/TikTok.

Supported references:

- Shopee PRIME: 6/7/8% excluding VAT by selected category; electronics requires explicit 7 or 8%. Effective3Mar2026. https://shopee.co.th/m/PRIME-Seller-Program
- LiveXtra: merchant confirms 2 or 3% excluding VAT under FSS/CCB eligibility; order base includes buyer payment + platform discount + buyer shipping. Published terms29May2025 must be confirmed against shop current terms. https://help.shopee.co.th/portal/4/article/178713
- Lazada Premium:8% excluding VAT, effective1Aug2026. One fee includes FSS/campaign vouchers; do not stack. Lazada University slides6,16–17: https://university.lazada.co.th/course/learn?id=42106&type=article
- TikTok BCD/FS:3.21% tax-inclusive on seller-discounted item revenue, exclusive per one item. Effective1Jan2025. https://seller-th.tiktok.com/university/essay?knowledge_id=7498481985029905&lang=en
- TikTok Growth is mandatory independently of campaign choice:696/803bps, small Non-Mall642/749bps,199THB per-item cap tax-inclusive, effective6May2026. Waiver/exemption are merchant-confirmed hypotheses, including remaining allowance. https://seller-th.tiktok.com/university/essay?knowledge_id=4831419884979969&lang=en
- Shopee/TikTok per-order fee1.07THB unless merchant confirms exemption; not a monthly fee. Payment rate3.21% is an editable starting assumption with explicit base; installment/special rates must be entered and confirmed. Commission is deliberately blank and VAT unknown by default.

Not covered: automatic Seller Centre integration, actual enrollment verification, new products with no order price, pre-orders, unrecorded affiliate/cofunding charges, or Shopee Flash Sale Dynamic Discount whose Seller Offer Price may differ from recorded post-voucher revenue. These are not silently treated as zero or offered as supported presets. Historical data before reference schedule dates are incomplete. User must check membership dates, shop/category/rates and all assumptions. Authoritative actuals still require posted settlement evidence.

Tests: independent satang goldens for three platforms, no double posted deductions, per-order payment/Live rounding, Growth per-item cap, small seller rate, unknown/date gates, tenant denial, schema tampering, no model calls, discount and break-even. Full existing backend suite/build checks required before cloud release. Deployment evidence belongs in verification/status/cost-log, not inferred from this document.
